# ✨ Overview

**El-Meshwar** is an intelligent transportation companion designed specifically for Egyptian users.  
The application helps users:

- Plan optimized routes
- Compare transportation methods
- Calculate trip costs
- Manage personal vehicles
- Track savings and analytics
- Enjoy gamified rewards

Built with scalability, clean architecture, and modern Flutter practices.

# ⚙️ Installation

## Prerequisites

- Flutter SDK >= 3.2.0
- Dart SDK
- Android Studio / VS Code
- Git

---

## Clone Repository

```bash
git clone https://github.com/DEPI-Flutter-Projects/Final_Graduation_Project.git
cd Final_Graduation_Project
```

## Install Dependencies

```bash
flutter pub get
```

## Configure Environment

Create a `.env` file:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

---

## Run Application

```bash
flutter run
```
